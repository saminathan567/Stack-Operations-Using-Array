# Stack Operations Using an Array in C

## Project Description
This project demonstrates the implementation of Stack operations using an array in C programming.

## Operations
- Push – Insert an element.
- Pop – Remove the top element.
- Display – Display Stack elements.

## Concepts Covered
- LIFO principle
- Array implementation
- Stack Overflow
- Stack Underflow
- Manual code tracing

## Language
C Programming
